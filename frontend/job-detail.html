Mô tả công việc
- Tham gia thiết kế kiến trúc, phát triển và tối ưu hóa hệ thống Backend Java phục vụ hàng triệu người dùng. - Xây dựng các RESTful API / gRPC service có tính bảo mật cao, độ sẵn sàng (high availability) và khả năng chịu tải tốt. - Thiết kế mô hình cơ sở dữ liệu (MySQL / PostgreSQL), tối ưu chỉ mục (index), tối ưu hóa câu truy vấn phức tạp và caching (Redis). - Làm việc chặt chẽ với đội ngũ Frontend, Mobile và Product Manager để hoàn thiện các tính năng nghiệp vụ cốt lõi. - Thực hiện code review, viết unit tests và integration tests nhằm đảm bảo chất lượng mã nguồn cao nhất.
Yêu cầu ứng viên
- Có từ 3 năm kinh nghiệm lập trình Backend với Java (Spring Boot, Servlet/JSP, Hibernate/JPA). - Thành thạo thiết kế RESTful API, hiểu rõ các giao thức HTTP, WebSocket, xác thực JWT, RBAC. - Kinh nghiệm làm việc với hệ quản trị CSDL quan hệ (MySQL, PostgreSQL) và hệ thống Cache (Redis/Memcached). - Hiểu biết về kiến trúc vi dịch vụ (Microservices), Message Broker (Kafka / RabbitMQ) và Docker / CI-CD là lợi thế lớn. - Khả năng tư duy logic tốt, kỹ năng giải quyết vấn đề hiệu quả và tinh thần trách nhiệm cao.
